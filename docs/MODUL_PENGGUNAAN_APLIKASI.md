# Modul Penggunaan User GenPro

Dokumen ini ditujukan untuk pengguna operasional aplikasi:

- Staff
- Supervisor / Admin Departemen
- HRD
- Admin Office

## Menu Staff

1. Dashboard
2. Absensi Kerja
3. Perbaikan Absen
4. Pengajuan Cuti / Izin / Sakit
5. Kalender Kerja
6. Log Kehadiran
7. Rekap In-Out
8. Laporan Statistik
9. Profil Saya

### Alur Harian Staff

1. Login aplikasi.
2. Absen masuk.
3. Bekerja sesuai jadwal.
4. Ajukan izin/cuti jika diperlukan.
5. Absen pulang.
6. Cek log kehadiran jika diperlukan.

## Menu Supervisor / HR / Admin

2. Approval Pengajuan
3. Approval Perbaikan Absen
4. Approval Absensi
5. Atur Jadwal Kerja
6. Kelola Shift
7. Data Karyawan
8. HR Personalia / Kontrak
9. Titik Radius GPS
10. Rekap Absensi
11. Laporan Keseluruhan

### SOP Approval

- Cek data pengajuan.
- Verifikasi alasan dan tanggal.
- Approve atau Reject.
- Pastikan data masuk ke rekap.

### SOP Perbaikan Absen

- Cek jam yang diajukan.
- Cocokkan dengan jadwal kerja.
- Approve jika valid.
- Pastikan status absensi menjadi complete.

## Troubleshooting

### Tidak Bisa Absen

- Pastikan GPS aktif.
- Pastikan berada dalam radius lokasi kerja.
- Pastikan koneksi internet stabil.

### Pengajuan Tidak Muncul

- Hubungi HR/Admin.
- Pastikan data karyawan aktif.

### Rekap Tidak Lengkap

- Cek approval absensi.
- Cek approval perbaikan absen.
- Pastikan jam masuk dan pulang sudah lengkap.

## Catatan

Dokumen ini khusus untuk pengguna aplikasi. Informasi developer, struktur database, multi-tenant, office, department, dan super admin dipisahkan ke dokumen Developer Guide.
