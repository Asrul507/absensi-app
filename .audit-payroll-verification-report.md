## 🔍 TROUBLESHOOTING GUIDE

If the Payroll menu doesn't appear, verify:

### 1. User Role
```javascript
// Check in browser console:
console.log(window.currentUser.role)  
// Should be: 'admin_all' or 'admin_hr'
```

### 2. Package Assignment
```javascript
// Check in browser console:
const client = Array.isArray(window.currentUser?.clients) 
  ? window.currentUser.clients[0] 
  : window.currentUser?.clients
console.log(client?.package_type)
// Should be: 'standard' or 'pro' (NOT 'basic')
```

### 3. Client Assignment
```javascript
// Check in browser console:
console.log(window.currentUser?.client_id)  
// Should have a UUID value
```

### 4. RLS Policy Check
```sql
-- Run in Supabase SQL Editor:
SELECT * FROM public.payroll_components LIMIT 1;
-- If returns data: RLS is working
-- If 403 error: RLS policy issue
```

### 5. Browser Console Errors
- Open DevTools (F12) → Console tab
- Look for errors related to payroll queries
- Check network tab for failed API requests
